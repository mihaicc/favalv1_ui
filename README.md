# favalv1-ui

React + Vite frontend for Faval.ai.

## Development

Install dependencies:

```bash
npm install
```

Start the dev server:

```bash
npm run dev
```

The app will be available at [http://localhost:3000](http://localhost:3000).

The dev server proxies API requests to the backend at `http://localhost:8000`, so make sure the backend is running as well.
